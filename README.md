
# 정비사업 비교 PPT형 정적 웹

## 바로 보기
`index.html`을 더블클릭하면 브라우저에서 바로 열립니다.

## 무료로 외부 공개하기

### GitHub Pages
1. GitHub에서 새 repository 생성
2. 이 폴더의 `index.html` 업로드
3. Settings → Pages
4. Deploy from a branch
5. Branch: main / root 선택
6. 생성된 URL을 공유

### Netlify Drop
1. https://app.netlify.com/drop 접속
2. 이 폴더 전체를 드래그 앤 드롭
3. 즉시 외부 공개 URL 생성

정적 HTML이라 별도 Python/Streamlit 서버가 필요 없습니다.
